# community-scripts

Community-Scripts-style Proxmox VE helper scripts.

## Mindwtr

Creates an unprivileged Debian 13 LXC and installs the official Mindwtr web/PWA plus the self-hosted Cloud/Sync server using Docker Compose.

### Installation

Run this on the Proxmox VE host:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/SaulGoodman1337/community-scripts/main/ct/mindwtr.sh)"
```

After installation:

- Web/PWA: `http://<LXC-IP>:5173`
- Cloud/Sync API: `http://<LXC-IP>:8787`
- Generated sync token: `/root/mindwtr.creds`
- Compose configuration: `/opt/mindwtr/compose.yaml`
- Environment configuration: `/opt/mindwtr/.env`
- Persistent Cloud data: `/opt/mindwtr/data`

### Updates

Inside the Mindwtr LXC simply run:

```bash
update
```

The `update` entrypoint is generated by the official community-scripts core. It runs the `update_script()` function from `ct/mindwtr.sh`, updates the Debian base system and Docker, pulls the latest official Mindwtr images, recreates the containers, verifies the Cloud service and removes unused Docker images.

### Changing the public URL

Mindwtr requires an exact CORS origin for the browser app. The installer uses the LXC IPv4 address detected during installation.

If the IP, hostname, port or reverse-proxy URL changes, edit:

```bash
nano /opt/mindwtr/.env
cd /opt/mindwtr
docker compose up -d
```

Adjust `MINDWTR_CLOUD_CORS_ORIGIN` and `MINDWTR_DEFAULT_CLOUD_URL` to match your deployment.
